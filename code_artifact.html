Sell-Side Bank · 卖方投行

JPM / MS / GS / Mizuho / SMBC

围绕做市商中介与机构融资业务，风控核心聚焦于 FRTB 敏感度验证、违约风险资本 (DRC)、VaR 回测与每日损益归因测试 (PLAT)。

主力岗位：Market Risk / Counterparty Credit Risk (CVA) / Model Risk
Asset Manager · 传统买方资管

BlackRock / PIMCO / Neuberger Berman

以 Long-Only 及多资产策略为主，追求跑赢基准的相对收益。依托 Aladdin / Barra 监控跟踪误差 (Tracking Error) 与主动因子暴露。

主力岗位：Investment Risk Associate / Multi-Asset Quant Risk
Hedge Fund · 多策略对冲基金

Millennium / Citadel / Point72 / Balyasny

高倍杠杆与多空对冲追求纯 Alpha。中央风控紧盯最大回撤硬止损线 (Max Drawdown)、因子拥挤度 (Crowding) 与独立衍生品估值签字。

主力岗位：Portfolio / Pod Risk Analyst / Valuation Analytics
